About

          

        

        

          
Feedback

          

            A bug report with the diagnostics already filled in, a question, or an idea. Each opens
            GitHub in your browser; nothing is sent from here on its own.
          

          

        

        

          
Reporting a problem

          

            Copies the version, the Java found, where things live, every server's status, the
            panel's own log and the last console lines of the selected server. No passwords and
            no webhook. Paste it into a GitHub issue.
