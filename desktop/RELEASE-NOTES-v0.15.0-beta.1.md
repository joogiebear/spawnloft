Two looks. Your choice.

This is a development preview of the new application theme selector. It is a
GitHub prerelease, not a stable release; stable installations stay on v0.14.0.

## Try the themes

Open **Settings → Appearance** and choose:

- **Classic** — the original blue palette, still the default.
- **SpawnLoft** — the website's charcoal surfaces, warm white text, and lime accents.

Changes apply immediately and are saved on this PC. Reopening the app keeps your
choice, including its setup screen. You can switch back at any time. Theme changes
do not move your data or change any server settings.

Buttons, inputs, dialogs, scrollbars, icons, and the processor chart follow the
selected palette. Server status, warnings, and errors keep their distinct colors.

Also fixes a quick-restart race: starting a server or database now waits for the
new process's state instead of accepting a leftover record from its previous run.

Install this beta manually to try it. This uses the same SpawnLoft installation
and data locations; it is not a separate sandbox app. If you prefer to return to
stable, install the latest stable installer from the release page.
