## Mac development previews

Mac and Windows now ship together as separate installers in one numbered development
prerelease. See [the desktop preview guide](PREVIEW.md) for downloads, update behavior,
Mac limitations, and the path to 1.0.

Older `0.15.0-mac.N` downloads stay available and unchanged. Install the newer
`0.15.0-beta.N` Mac DMG manually to move to the paired release series.
