SpawnLoft First run

Where should SpawnLoft keep your servers?

Worlds, downloaded server jars and backups go here. Not the program itself — that is already installed. You can move this later from Settings.

A fresh server takes about 300 MB. Worlds grow from there.
Jars, backups and settings stay in the data folder above.
Checking for Java… Minecraft servers run on Java. SpawnLoft needs one installed.
